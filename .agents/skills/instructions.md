# Coding Instruction for AI Agents

## Project Overview
This codebase is web client to expiry date manager project.
This codebase will contain React components and pages to create various features
of the project. For example, it will allow users to login/register, scan product
UPC code using camera, manage the expiry dates of the products.

## Tech Stack & Environment
- React (v19.x.x)
- Framework: React + Vite
- CSS: Tailwindcss

## Project Structure
- `src/` - Source code
- `src/components` - Reusable components
- `src/pages/` - UI pages specific to app
- `src/utils/` - Utility functions

## Architecture Patterns
- Follow functional components with primary component as App.jsx.
- Split out the component if the .jsx file becomes more than 500 lines. There can be exceptions, but ask for review before keeping a component file beyond 500 lines.

## Coding Instructions
1. Always get approval before making changes.
